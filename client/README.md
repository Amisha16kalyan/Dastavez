# Dastavez - Frontend (React.js + Vite)

A real-time collaborative document editor built with **React.js**, **Vite**, **Yjs (CRDT)**, and **ProseMirror**.

## 🚀 Features
- **Pure JavaScript & React.js (`.jsx`)**: No TypeScript or Next.js complexity.
- **Real-Time Collaboration**: Powered by Yjs CRDT and WebSockets.
- **Multi-User Presence & Awareness**: Live cursor positions and user names.
- **Rich Text Toolbar**: Bold, Italic, Underline, Headings (H1/H2/H3), Undo/Redo.
- **Share Link**: One-click link copying, share dialog, and multiple rooms (`?doc=...`).
- **Export**: Download documents as `.txt` files.

## 🛠️ How to Run
```bash
npm run dev
```
Runs at [http://localhost:3000](http://localhost:3000).
